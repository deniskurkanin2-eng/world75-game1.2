МИР: 75% — версия 3

Публикация:
1. Открой репозиторий GitHub.
2. Замени старый index.html новым.
3. Если используешь ZIP, распакуй архив и загрузи index.html в корень репозитория.
4. В Settings -> Pages проверь, что публикация включена.

Изменения:
- Флаги у стран и в списках выбора.
- Поиск по буквам в выборе страны, выборе цели захвата и дипломатии.
- Пошаговые ходы удалены. Заводы автоматически приносят деньги каждые 20 секунд.
- Стартовые деньги, заводы и армия различаются по странам. Для США и Молдовы заданы отдельные параметры.
- Захватывать можно только соседние страны, имеющие общую сухопутную границу с твоими территориями.
- Интерфейс адаптирован для телефона.

Важно: список сухопутных границ пока заполнен не для всех государств. Игра одиночная; общий мультиплеер с другом требует сервера.
